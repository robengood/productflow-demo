# ProductFlow — демонстрационный каталог товаров

Учебный проект на синтетических данных, подготовленный с использованием AI-инструментов. Коммерческого заказчика и внедрения нет.

**Публичный каталог:** будет указан после проверки GitHub Pages.

ProductFlow проверяет и нормализует товарную CSV-таблицу отдельной Python-программой. GitHub Pages показывает готовый статический HTML-каталог; сайт не принимает CSV и не запускает Python в браузере.

В репозитории доступны два проверенных архива:

- `productflow-github-ready.zip` — исходный код, синтетические данные, тесты, документация, PDF-кейс и проверенные выходные файлы. Распакуйте архив, чтобы изучить структуру проекта.
- `productflow-pages-ready.zip` — готовая статическая версия каталога.

Для просмотра скачайте Pages-архив и откройте `pages/index.html` либо воспользуйтесь публичной ссылкой выше после завершения публикации.

## Проверенная демонстрация

- 20 синтетических входных записей: 12 принятых товаров и 8 отклонённых строк.
- 10 ошибок данных и 11 зарегистрированных изменений формата.
- 46 автоматических тестов в подготовленном выпуске.

Полные условия, ограничения, инструкции запуска и аудит находятся в исходном архиве (`productflow/README.md`, `productflow/docs/`). CSV обрабатывается локально из командной строки; сайт — только просмотр готового результата.
