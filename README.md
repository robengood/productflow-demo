# ProductFlow — демонстрационный каталог

[Открыть каталог](https://robengood.github.io/productflow-demo/) · [Исходный проект и тесты](https://github.com/robengood/productflow-demo)

Учебный проект на синтетических данных, подготовленный с использованием AI-инструментов. Коммерческого заказчика и внедрения нет.

Python отдельно проверяет и нормализует CSV. GitHub Pages показывает готовую статическую HTML-страницу; загрузки CSV и обработки данных в браузере нет. Каталог предназначен для просмотра.

## В репозитории

- [Исходный код, данные, тесты, документация, PDF и выходные файлы](productflow-github-ready.zip) — архив скачайте и распакуйте, чтобы изучить структуру проекта.
- [Готовая статическая версия](productflow-pages-ready.zip) — архив содержит сайт и ресурсы, которые публикуются по ссылке выше.
- .github/workflows/pages.yml — ручная публикация Pages; перед выкладкой workflow запускает тесты и повторно обрабатывает демонстрационный CSV.

## Подтверждённый пример

20 синтетических исходных записей → 12 принятых товаров и 8 отклонённых строк. Программа зарегистрировала 10 ошибок в данных и 11 изменений формата. Набор содержит 46 автоматических тестов; [последняя сборка и публикация](https://github.com/robengood/productflow-demo/actions).

Это небольшой демонстрационный проект, а не коммерческий интернет-магазин: нет корзины, оплаты или загрузки файла через браузер.
