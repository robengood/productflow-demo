# ProductFlow: аудит до доработки

Проверены реальные исходники, запуск CSV-обработки, 26 существующих тестов, каталог в браузере и четыре страницы PDF. Исходный комплект сохранён отдельно в архиве резервной копии.

## Приоритеты

Критичных сбоев в основном сценарии не обнаружено: 20 записей дают 12 принятых товаров, 8 отклонённых записей и 10 ошибок. Все 26 исходных тестов прошли при повторном запуске.

| Приоритет | Наблюдение до исправления | Решение |
| --- | --- | --- |
| Существенный | `ß-1` принимается как `SS-1`, хотя допустим только ASCII-артикул. Воспроизведено отдельным CSV. | Проверять исходные символы до изменения регистра. |
| Существенный | Название `\u0000=DEMO` принимается без ошибки. Воспроизведено CSV с нулевым символом. | Отклонять скрытые управляющие символы, сохранять причину и исходное значение. |
| Существенный | Пробелы, регистр и денежный формат меняются без журнала. | Записывать точные значения до и после; сохранять отклонённые записи в JSON целиком. |
| Существенный | Таблица результатов содержит служебный столбец, который сам обработчик считает неизвестным. | Сделать normalized.csv совместимым со входной схемой; происхождение хранить в отчёте. |
| Существенный | На экране 1440 × 1000 первая карточка начинается на y≈991 px. Главный блок не объясняет процесс. | Сократить верхний блок, показать назначение и товары раньше. |
| Существенный | 12 товаров используют 3 изображения; держатель и подставка выглядят как лоток. | У каждого демо-товара своя условная иллюстрация; для неизвестного SKU честная заглушка. |
| Существенный | PDF уменьшает скриншоты настолько, что описания карточек практически не читаются. | Крупные скриншоты и отдельные увеличенные фрагменты; таблица с фактическими примерами до/после. |
| Косметический | Формы «1 товара» и «1 товаров» возможны при другом CSV. | Подпись «Позиций: N», не зависящая от склонения. |
| Косметический | Описания повторяют «условный», «синтетическое описание», «демонстрационный товар». | Одно заметное обозначение демо; краткие содержательные описания. |
| Косметический | Категории похожи на фильтры, но только перемещают страницу. | Явно назвать их ссылками перехода и визуально оформить как навигацию. |
| Косметический | CSS записан одной длинной строкой; сборка PDF содержит фиксированные дату и количество тестов. | Отформатировать CSS; брать проверяемые показатели из актуальных файлов. |

## Что сохраняется

Python без сторонних зависимостей для приложения, Decimal для цен, CSV/JSON-отчёты, экранирование HTML, исключение всех повторов SKU, адаптивная сетка, локальные SVG и статическая HTML-страница. Загрузка через браузер, база данных, авторизация и оплата не нужны для этого кейса.

## Граница аудита

Проверка небольшого локального проекта, не аудит промышленной системы и не подтверждение совместимости с конкретной CMS. Факты о финальном состоянии и проверках после исправления находятся в QA_REPORT.md.
