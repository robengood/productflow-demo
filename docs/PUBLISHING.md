# Публикация и обновление ProductFlow

Каталог и исходный проект уже доступны публично:

- [Открыть каталог](https://robengood.github.io/productflow-demo/)
- [Открыть репозиторий](https://github.com/robengood/productflow-demo)
- [Проверить запуски GitHub Actions](https://github.com/robengood/productflow-demo/actions/workflows/pages.yml)

## Как устроена публикация

Код, тесты, документация и синтетические CSV лежат в обычных папках в корне репозитория.
Для просмотра исходников архив скачивать не нужно.

Python запускается отдельно: он читает CSV, проверяет записи и создаёт отчёты вместе с HTML.
GitHub Pages не принимает файлы от посетителей и не запускает Python в браузере. Он показывает
статические файлы каталога, подготовленные GitHub Actions.

Workflow находится в `.github/workflows/pages.yml` и запускается вручную. Он выполняет тесты,
обрабатывает `data/products_demo.csv`, проверяет ссылки на изображения и стили, затем передаёт
готовую папку сайту GitHub Pages. Обычная загрузка изменений в репозиторий сайт автоматически
не пересобирает.

## Как обновить опубликованный каталог

1. Внесите изменения в исходные файлы и запустите тесты по инструкции в корневом README.
2. Сохраните изменения новым коммитом в существующем репозитории. История коммитов при этом
   продолжается; переписывать её не требуется.
3. На GitHub откройте **Actions → Publish ProductFlow (manual) → Run workflow**.
4. В Actions выберите **Publish ProductFlow to GitHub Pages** и нажмите **Run workflow**.
5. Дождитесь успешного завершения сборки и публикации. При ошибке не считайте сайт обновлённым.
6. Откройте адрес каталога в обычном браузере и проверьте изображения и ссылки на выходные файлы.

Удаление ZIP из текущей версии репозитория убирает его из актуального списка файлов, но не
стирает прежний коммит из истории Git. Переписывать историю для этой демонстрации не нужно:
в архивах синтетические данные и проверенный код, личных материалов в них не обнаружено.

## Ограничения

Это демонстрационный проект на синтетических данных, подготовленный с использованием AI.
Коммерческого заказчика и внедрения нет. В браузере нет загрузки CSV, корзины, оплаты, API
или базы данных. Условия открытой лицензии на повторное использование исходников отдельно
не выбраны.
