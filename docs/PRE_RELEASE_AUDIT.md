## B. Отчёт об исправлениях

write_outputs сохраняет прежние функции и формат данных. Новые commit_outputs/check_output_targets:
проверка файловой идентичности, hardlink и перенаправлений дочерних путей; подготовка всех файлов
во временной папке; замена через os.replace; восстановление прежних байтов при обычном сбое.
При ошибке самого восстановления резервная папка сохраняется и выдаётся понятное сообщение.
Непредусмотренные файлы в папке вывода не удаляются. Приложение не стало сервером.

Наличие каждого файла, на который ссылается HTML, проверяется до вывода.
Нужные ресурсы выбираются по реальным ссылкам. Старые неиспользуемые файлы рабочей папки
могут оставаться, но не входят в чистый выпуск. Обезличивание журналов сохраняется при повторном запуске record_checks.
prepare_release/package_project не отправляют данные и не создают GitHub-репозиторий.
Workflow остаётся ручным; теперь загружает только site/ после тестов, обработки и отбора файлов.

Визуальная композиция, тексты карточек и навигация сохранены: объективных оснований для редизайна не найдено.
Интерфейс не обещает покупку или браузерную обработку CSV. SVG обозначены иллюстрациями.
В README/CASE/LEARNING_GUIDE/QA/PDF обновлены тесты и ограничения; прежний AUDIT обозначен историческим.
PDF содержит актуальные desktop/mobile кадры и реальные примеры DS-001, DUP-001, BAD-002, BAD-003.

## D. Оставшиеся ограничения

- Проверен один Chromium/Windows/Python 3.12.14; Safari/Firefox, реальные устройства, полный WCAG,
  нагрузка и исчерпывающий перебор Unicode не проверялись. Hover указателя — ограничение инструмента.
- В этом компьютере обычный py -3 сообщает об отсутствии установленного Python. Аудит использовал
  доступный интерпретатор 3.12.14. Установка Python — реальная предпосылка инструкции README.
- Несколько os.replace не являются общей транзакцией при аварии процесса/питания. Конкурентные запуски
  и изменение файлов другой программой во время сборки не поддерживаются. Нужна отдельная папка вывода.
- Ошибка отката может оставить неполный результат, но резервные файлы сохраняются. Автовосстановления после аварии нет.
- CSV максимум 5 МиБ, фиксированные категории, ASCII SKU; отказ формул консервативен. Числовой SKU
  при открытии Excel требует текстового импорта, чтобы редактор сам не удалил ведущие нули.
- Нет загрузки CSV в браузере, корзины, API, базы, CMS и проверенного коммерческого внедрения.
- Проверка известных форматов секретов и метаданных не является исчерпывающим DLP/SCA/пентестом.
  Внешних зависимостей приложения нет; библиотеки изготовления PDF не подвергались полному CVE-аудиту.
- SVG локальные, шрифтовые файлы не распространяются. Происхождение и условия Arial описаны
  в ASSET_PROVENANCE.md по документации Microsoft; юридическая исключительность AI-материалов не утверждается.
- Resume B Final недоступно: согласованность резюме не проверена, в нём могут оставаться старые числа.
- GitHub Actions удалённо не запускался, настоящая публичная ссылка отсутствует. Нельзя объявить проверенным
  публичный сайт до разрешения на публикацию и последующего открытия реального адреса.
