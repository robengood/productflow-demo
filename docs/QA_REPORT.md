## Команды и фактический вывод

Использован реальный доступный Python 3.12.14. `python` ниже означает выбранный интерпретатор:

```text
python -m unittest discover -s tests -v
Ran 46 tests
OK

python catalog.py data/products_demo.csv --output output
{"input_records": 20, "accepted_records": 12, "rejected_records": 8, "issue_count": 10}
```

Обе команды завершились с кодом 0. При --strict на этом наборе ожидается код 1 и сохранённые отчёты;
это проверяет end-to-end тест. Неисправимый вход или небезопасный выход дают код 2.
`python tools/record_checks.py` воспроизводит обычный набор и проверку артефактов.
Распаковка чистого ZIP и повторная сборка проверяются tools/package_project.py;
на извлечённой копии прошли 46 тестов, CLI завершился с кодом 0, новая сборка
побайтно совпала со статическим комплектом. CRC и файлы архива проверены.
Фактический протокол находится рядом с архивами в release-verification.json.

## Ограничения

Нет промышленного аудита, нагрузки, реальных устройств, Safari/Firefox и полного аудита доступности.
file:// не проверен; использовался локальный HTTP. CSV ограничен 5 МиБ и хранится в памяти.
Откат покрывает обычные ошибки записи; аварийное прекращение процесса, питание и конкурентные запуски не проверены.
Ошибка самого отката сохраняет резервную папку; автоматическое восстановление после аварии не реализовано.
Нет браузерной загрузки CSV, покупки, CMS, API, базы данных. Правила категорий и числа — условия демо.
Формулоподобные тексты отклоняются консервативно; CSV в Excel импортируйте с текстовым типом SKU.
На дату аудита 09.10.2026 проект ещё не был опубликован. Публичный Pages и GitHub Actions проверены позднее; актуальные ссылки приведены в README.md.
