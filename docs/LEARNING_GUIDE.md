# ProductFlow простыми словами

## Что показывать студии

«Это мой учебный кейс на вымышленных товарах, подготовленный с помощью AI.
Программа проверяет CSV, отделяет ошибочные записи, сохраняет изменения и собирает каталог.
Я могу показать исходную таблицу, конкретную ошибку, результат обработки и журнал тестов».

Говорите «я могу объяснить и повторить» только после того, как сами выполните запуск и упражнение ниже.
Не заявляйте самостоятельное написание всего кода или опыт коммерческого внедрения.

## Как всё работает

1. Вы передаёте Python путь к таблице. В браузере загрузки нет.
2. Программа читает заголовки и записи, проверяет каждое поле и повторения артикулов.
3. Понятные различия формата приводит к общему виду: « ds-001 » становится «DS-001»,
   «1 290,00» — «1290.00». Это фиксируется в журнале.
4. Неоднозначные или ошибочные записи исключает: например, отрицательную цену не превращает в положительную.
5. Сохраняет четыре файла данных и HTML-страницу с принятыми товарами.
6. Браузер показывает страницу. После изменения CSV нужно снова запустить Python.

Обработка собрана в одном небольшом файле catalog.py:
`process_csv` читает и проверяет; `parse_price` и `parse_stock` разбирают числа;
`render_catalog` создаёт разметку; `write_outputs` записывает результаты;
`commit_outputs` готовит новые файлы и восстанавливает предыдущие при обычном сбое записи;
`main` принимает команду запуска и сообщает об ошибках.

## Зачем нужны технологии

| Технология | Роль |
| --- | --- |
| Python | Правила проверки, нормализация, отчёты и сборка страницы. |
| CSV | Простая таблица обмена данными. Заголовки задают смысл столбцов. |
| Decimal | Точное десятичное представление цены без погрешностей двоичного float. |
| JSON | Подробный машинный отчёт, в том числе точные ошибочные данные. |
| HTML | Содержание: заголовки, карточки, ссылки и таблица ошибок. |
| CSS | Цвета, размеры, отступы и число колонок на разных экранах. |
| SVG | Локальные условные иллюстрации товаров; это не фотографии. |
| unittest | Запускает повторяемые проверки и сообщает, совпало ли ожидаемое с фактическим. |

AI помог подготовить код, оформление, тесты и документы. Во время обычного запуска AI не вызывается.
У приложения нет платных API или внешних зависимостей.
ReportLab нужен отдельно для изготовления PDF, а не для обработки товаров.

## Что считается ошибкой

Пустое обязательное поле; повторный артикул; недопустимые символы в нём;
неизвестная категория; неверная цена; дробный или отрицательный остаток;
неверное число столбцов; слишком длинный текст; скрытые управляющие символы;
текст, похожий на формулу. Повторный артикул исключается во всех записях —
программа не выбирает случайно, какой из конфликтующих товаров верный.

Если целый файл не читается, не соответствует UTF-8 или имеет неверный заголовок,
сборка останавливается. Старый каталог может остаться на месте: сообщение и код завершения покажут,
что нового результата нет.

## Как читать результат

В основном CSV 20 записей, из них принято 12, отклонено 8.
Ошибок 10, потому что у двух записей по две ошибки.
11 изменений — это изменения отдельных полей у принятых товаров, а не 11 исправленных ошибок.

normalized.csv содержит пригодные по правилам демо товары.
issues.csv объясняет отклонения. changes.csv показывает «до → после».
report.json хранит полные ошибочные записи и контрольную сумму исходного файла.
Контрольная сумма помогает подтвердить, какой именно файл был обработан.

46 тестов проверяют отдельные правила, границы чисел, необычные символы,
повторы, пустой ввод, ошибки файла, защиту исходника, безопасный HTML,
полный запуск, повторяемость и повторную обработку выгрузки.
Девять новых проверок относятся к файловым ссылкам, отсутствующей картинке,
сбоям подготовки, замены и восстановления результата.
Тесты не доказывают отсутствие всех возможных ошибок. Вёрстку отдельно проверяли в браузере.

## Мини-репетиция на 10 минут

1. Запустите команды из README и откройте каталог.
2. Найдите DS-001 в исходном CSV, затем в normalized.csv и changes.csv. Объясните четыре изменения.
3. Найдите BAD-002: цена -100. Покажите причину в issues.csv и отсутствие карточки.
4. Сделайте копию products_demo.csv. В копии замените цену BAD-002 на 100.
   Запустите её с новой папкой вывода. Ожидается 13 принятых, 7 отклонённых, 9 ошибок.
   Это упражнение для вас, его выполнение здесь не заявляется.
5. Запустите тесты. Объясните отличие тестового сообщения «OK» от визуальной проверки карточек.

## Что означает готовность к публикации

GO относится к проверенному чистому комплекту. Это не обещание промышленной надёжности.
Python запускается до публикации, Pages только раздаёт HTML и ресурсы.
При сбое обычной записи программа пытается восстановить предыдущий комплект.
Отключение питания или два параллельных запуска могут нарушить комплект; так проект не проверялся.
Работайте в отдельной папке вывода и проверяйте код завершения.

При импорте CSV в Excel задайте тип колонки SKU как текст: табличный редактор может сам
преобразовать числовой артикул или удалить ведущие нули. Байты CSV программа сохраняет по своим правилам.

На вопрос «Почему раньше было 37, а теперь 46 тестов?» отвечайте:
«Предрелизный аудит нашёл пробелы в защите файлов. Их исправили и добавили девять регрессионных проверок».
На вопрос «Тесты означают отсутствие ошибок?» — «Нет. Они подтверждают конкретные сценарии;
проверка браузера и ограничения описаны отдельно».
