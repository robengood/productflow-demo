# Ресурсы и условия публикации

Проверено 09.10.2026. Это описание происхождения и обнаруженных условий, не юридическое заключение.

| Материал | Происхождение / проверка | Что входит в выпуск |
| --- | --- | --- |
| CSV | Синтетический набор для этого учебного проекта; реальные клиентские материалы отсутствуют | 3 примера и результаты основного набора |
| Python, HTML, CSS, тесты, документы | Подготовлены для проекта с помощью AI; коммерческий опыт не заявляется | Исходники и проверенная документация |
| SVG | Условные иллюстрации созданы локальным tools/build_illustrations.py; внешние фотографии, логотипы и ссылки отсутствуют | 12 рисунков товаров, placeholder, favicon |
| Скриншоты | Реальные кадры локального Chromium, показывают синтетический каталог | Актуальные кадры пяти размеров и фрагменты |
| Web-шрифты | Используется системный CSS font stack, загрузок TTF/WOFF нет | Только названия системных шрифтов в CSS |
| PDF-шрифт | Arial Regular и Bold из установленной Windows; fsType=8 у обоих файлов, в PDF встроены подмножества | Готовый PDF; исходные файлы шрифтов не распространяются |

[Microsoft Font FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq) разрешает указание системных
шрифтов в CSS, отдельно ограничивает копирование Windows-шрифтов на веб-сервер и описывает встраивание
в документы с соблюдением флагов шрифта. Здесь TTF/WOFF не публикуются.
Повторная генерация PDF с другим шрифтом требует проверки его собственных условий.

Обнаруженных заимствованных клиентских материалов и ресурсов с неизвестной лицензией нет.
Это не гарантия исключительных авторских прав на AI-материалы и не анализ товарных знаков во всех странах.
Названия товаров условные, они не подтверждают связь с реальным брендом.
Отдельная открытая лицензия на повторное использование исходников пока не выбрана владельцем.
